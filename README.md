# Achieved Orbit

One line of office comedy: a standup with 14 people, 9 updates, and
one man who has said "circling back" so many times he has achieved
orbit. Corporate language, taken literally, becomes orbital mechanics
— and every office has the satellite.

The program clears the contents of the output directory and writes the
line to `entry.txt`, byte for byte, with no trailing newline.
